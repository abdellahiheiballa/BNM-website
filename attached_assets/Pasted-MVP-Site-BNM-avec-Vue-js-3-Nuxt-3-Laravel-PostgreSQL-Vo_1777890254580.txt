Je souhaite créer un MVP fonctionnel pour le site web de la Banque Nationale de Mauritanie (BNM).

## Stack technique à utiliser
- **Frontend** : Vue.js 3 + Nuxt 3 (mode SPA avec SSR désactivé pour simplicité)
- **Styling** : Tailwind CSS
- **Backend** : Laravel 11 (API REST)
- **Base de données** : PostgreSQL
- **Serveur local** : XAMPP (Apache + PostgreSQL)

## Pages à créer (frontend)
1. **Accueil** (`/`) : Hero, offres principales, actualités récentes, témoignages
2. **Particuliers** (`/particuliers`) : Comptes, cartes, épargne, crédits

9. **À propos** (`/a-propos`) : Histoire de la banque
10. **Simulateur de crédit** (`/simulateur`) : Calculateur de mensualités

## Composants interactifs à implémenter

### 1. Simulateur de crédit classique (Laravel API + frontend)
- Champs : Montant (100k - 50M MRU), Durée (1-25 ans), Taux (5.5% par défaut)
- Calcul : Mensualité = P * (r*(1+r)^n) / ((1+r)^n - 1)
- Affichage : Mensualité, Coût total du crédit, Intérêts totaux

### 2. Simulateur Murabaha (finance islamique)
- Principe : Prix d'achat + Marge bénéficiaire (pas d'intérêts)
- Champs : Prix du bien, Apport personnel, Marge (3-8%), Durée
- Affichage : Mensualité, Montant financé, Coût total

### 3. Formulaire de contact
- Champs : Nom, Email, Téléphone, Sujet, Message
- Validation frontend + envoi API Laravel
- Stockage en base de données
- Notification email (configuration .env)

### 4. Newsletter
- Champs : Email
- Inscription avec double opt-in simplifié
- Stockage dans table `newsletter_subscribers`

## 🚀 Script de démarrage rapide (`start.bat`)

```batch
@echo off
echo ========================================
echo   BNM - Demarrage du projet
echo ========================================
echo.

REM Démarrer PostgreSQL via XAMPP
echo [1/4] Demarrage de PostgreSQL...
net start postgresql-x64-15 2>nul
if %errorlevel% neq 0 (
    echo ERREUR: PostgreSQL non demarre. Verifiez XAMPP.
    pause
    exit /b 1
)

REM Démarrer Apache
echo [2/4] Demarrage d'Apache...
net start apache2.4 2>nul

REM Démarrer backend Laravel
echo [3/4] Demarrage du backend Laravel...
cd backend
start cmd /k "php artisan serve --host=0.0.0.0 --port=8000"

REM Démarrer frontend Nuxt
echo [4/4] Demarrage du frontend Nuxt...
cd ../frontend
start cmd /k "npm run dev -- --host --port=3000"

echo.
echo ========================================
echo   Site accessible sur le reseau local:
echo   Frontend : http://%COMPUTERNAME%.local:3000
echo   Backend  : http://%COMPUTERNAME%.local:8000
echo ========================================
echo.
echo Appuyez sur une touche pour quitter...
pause >nul

🔧 Problèmes courants et solutions
Problème	Solution
PostgreSQL ne démarre pas	Vérifier C:\xampp\pgsql\data\postgresql.conf, décommenter port = 5432
CORS bloque les requêtes	Ajouter '*' dans config/cors.php pendant le dev
Les images ne s'affichent pas	Vérifier les chemins, utiliser des URLs absolues
npm run dev échoue sur réseau	Ajouter --host 0.0.0.0 et désactiver firewall
Les autres machines n'accèdent pas	Désactiver temporairement le pare-feu Windows
